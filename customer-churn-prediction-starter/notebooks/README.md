# Notebooks

Place the original Jupyter Notebook for the Customer Churn Prediction project in this folder.

A useful notebook structure is:

1. Imports and configuration
2. Dataset loading and inspection
3. Data cleaning and preprocessing
4. Exploratory data analysis
5. Train/test split and SMOTEENN
6. Model training
7. Evaluation and comparison

Keep the notebook's data path aligned with the instructions in `../data/README.md`.
