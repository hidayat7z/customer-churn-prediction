# Dataset

The project uses the **Telco Customer Churn** dataset published on Kaggle:

https://www.kaggle.com/blastchar/telco-customer-churn

Download the CSV from Kaggle and place it in this directory's `raw/` folder. The dataset is not included in this repository; follow Kaggle's dataset terms when downloading or redistributing it.

If the downloaded CSV has a different filename from the one referenced in your notebook, update the notebook's data-loading path.
